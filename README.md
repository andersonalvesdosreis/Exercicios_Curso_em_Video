# 🐍 Meus Exercícios de Python

Bem-vindo(a) ao meu repositório de estudos de Python! 🚀

Este repositório contém todos os exercícios resolvidos durante a minha jornada de aprendizado em Python, divididos desde os conceitos mais básicos até a Programação Orientada a Objetos (POO).

## 📁 Estrutura do Repositório

O repositório está organizado nas seguintes pastas, representando minha evolução nos estudos:

### 🌍 [Mundo 1](./mundo_1)
Foco nos **Fundamentos** da linguagem.
* Primeiros comandos e scripts.
* Tipos primitivos e saída de dados.
* Operadores aritméticos.
* Utilizando módulos.
* Manipulação de texto (Strings).
* Condições (Parte 1).

### 🌍 [Mundo 2](./mundo2)
Foco em **Estruturas de Controle**.
* Condições aninhadas (`if`, `elif`, `else`).
* Estrutura de repetição `for`.
* Estrutura de repetição `while`.

### 🌍 [Mundo 3](./mundo3)
Foco em **Estruturas Compostas** e organização de código.
* Tuplas, Listas e Dicionários.
* Funções (Parte 1 e 2).
* Modularização e Pacotes.
* Tratamento de Erros e Exceções.

### 🧩 [Mundo POO](./mundo_POO)
Foco em **Programação Orientada a Objetos**.
* Criação de Classes e Objetos.
* Atributos e Métodos.
* Encapsulamento.
* Herança e Polimorfismo.
